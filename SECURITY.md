# Security

This is an initial 0.1.x local CLI. Do not submit secrets, real personal records or private coordinates in public issues. Inspect locally generated output before sharing. Input budgets and strict parsers reduce accidental misuse; they do not make hostile input harmless. Use an unprivileged disposable environment for untrusted files. The program does not fetch external resources, install dependencies at runtime or modify source inputs. Synthetic example generation writes only into a new directory and refuses overwrite.

If GitHub private vulnerability reporting is available, use it; otherwise open a minimal issue requesting a private reporting route without exploit payloads or sensitive data. No response deadline is guaranteed. Report the affected commit/version and a synthetic reproduction once a private route is established. Do not weaken validation or suppress an unresolved security finding.
